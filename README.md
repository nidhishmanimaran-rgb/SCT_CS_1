# Caesar Cipher - Encryption & Decryption Program

A simple Python program that implements the **Caesar Cipher** algorithm for encrypting and decrypting text messages using a shift value.

---

## 📌 Features

- Encrypt text messages
- Decrypt encrypted messages
- Brute force decryption (tries all possible shifts)
- Supports:
  - Uppercase letters
  - Lowercase letters
  - Numbers and symbols remain unchanged
- User-friendly menu interface

---

## 📖 About Caesar Cipher

The Caesar Cipher is one of the oldest encryption techniques.

It works by shifting each letter in the message by a fixed number of positions in the alphabet.

### Example

Message:
HELLO

Shift:
3

Encrypted Message:
KHOOR
